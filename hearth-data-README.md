# Hearth & Hope — nationwide data

Dignity-first support directory. **No Planned Parenthood, abortion clinics, or abortion referrals.**

## Centers (verified)

- **~2,600+ real local listings** + national helplines across all 50 states + DC.
- **Primary:** Option Line public store-locator (Heartbeat International), retrieved **2026-09-23**. Network states centers do not offer or refer for abortion.
- **Secondary:** Birthright public chapter directory (same date); geocoded via SimpleMaps ZIP centroids when needed.
- **Helplines:** Care Net (800-395-4357), Option Line (800-712-4357), Birthright (800-550-4900).
- Exclusions: PP / abortion clinic keywords; closed locations.
- Rebuild: `python3 scripts/build-real-centers.py`
